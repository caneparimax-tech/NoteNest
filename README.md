# NoteNest
Semester-long team project for sharing and managing course notes between students and instructors.

NoteNest is a web application developed as a three-person semester project during my junior year.

The goal of the project was to create a central place for students and instructors to manage and share course notes. Students can upload notes for specific courses, view notes shared by other students, and keep course materials organized in one place.

Instructors can oversee course sections and help manage the content available to students. The application also includes admin functionality for managing courses, sections, users, and enrollment.

## Features

- Student, instructor, and admin user roles
- Course and section management
- Student enrollment
- Uploading and sharing course notes
- Viewing and organizing notes by course
- Instructor oversight of course content
- User login and account management

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- PDO

## Project Background

This project was completed by a three-person team over the course of a semester during my junior year. It was designed to give students an easier way to share notes with classmates while allowing instructors to oversee their courses and course content.
